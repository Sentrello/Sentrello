# Getting started

Before any of it, if you would rather look than read:
**[What it looks like](/getting-started/what-it-looks-like)** is the free core,
screen by screen. It is not a step, and nothing below depends on it.

Then four short pages, in order:

1. **[Install](/getting-started/install)**: one command, on a server you
   control.
2. **[Configure](/getting-started/configure)**: your business details, tax,
   email and payments.
3. **[Check it works](/getting-started/testing)**: walk one job through before
   you rely on it.
4. **[Getting help](/getting-started/support)**: where to look, and what to
   send us.

If you only do one of these carefully, make it the third.
