# Modules

Each of these is a complete application in its own right, and each one knows
about the rest of Sentrello. Buy one, or several, and they appear inside the
instance you already run.

| Module | What it does |
|---|---|
| [Booking](/modules/booking) | A booking page customers use themselves, and a diary that stays honest |
| [Documents](/modules/documents) | The business's files, and warnings before one expires |
| [Shop](/modules/shop) | Sell online, with orders and money landing in the same books |
| [Newsletter](/modules/newsletter) | Mailing lists and campaigns, done lawfully |
| [Docs](/modules/docs) | Publish documentation from your own repository |

They are designed to combine. A booking creates a contact; a shop order posts
to the ledger; a document attaches to a customer. Nothing needs re-entering
because two modules share the same records.
