# Trademark Policy

**Last Updated:** August 17, 2026

Sentrello LLC ("Company," "we," "us," or "our") protects the integrity of the Sentrello brand, software ecosystem, and user community. While the source code for **Sentrello Core** is available under the GNU Affero General Public License v3.0 (AGPLv3), open-source software licenses **do not** grant trademark rights. 

This Trademark Policy outlines the allowed and prohibited uses of our brand assets.

---

## 1. Covered Marks
This policy applies to all trademarks, service marks, trade names, software names, domain names, and brand assets owned by Sentrello LLC, whether registered or unregistered, including but not limited to:
* **Sentrello**
* **Sentrello Core**
* **Sentrello Pro**
* Any future logos, wordmarks, slogans, or distinctive visual assets associated with Sentrello LLC.

---

## 2. Software Forks and Modified Versions

### Mandatory Renaming & Rebranding
If you fork, modify, or redistribute the `Sentrello/Sentrello` repository—or build custom packages, binaries, or Docker images derived from it—you **must completely remove all Sentrello brand assets** and rename your project.
* **Renaming Requirement:** You must adopt a distinct name that does not include "Sentrello" or any confusingly similar variation.
* **Asset Removal:** You must remove all Sentrello logos, wordmarks, and branding elements from the source code, user interface, documentation, and metadata before distribution.

### Factual Statements & Source Attribution
You may make truthful, non-confusing statements regarding the origin of your modified code solely for attribution purposes (e.g., *"This project is a fork of the AGPLv3 open-source code originally developed by Sentrello"*). You must not imply endorsement, sponsorship, or affiliation with Sentrello LLC.

---

## 3. Strictly Prohibited Uses

Unless you have explicit written permission from Sentrello LLC, you may **not**:
* **Domains & Handles:** Register, use, or operate any domain name, website URL, social media handle, or online account containing "Sentrello" (e.g., `sentrello-hosting.com`, `@SentrelloTips`).
* **Package Registries:** Publish public packages, containers, or modules containing "Sentrello" on third-party registries including Docker Hub, npm, PyPI, GitHub Packages, or Linux package managers.
* **Commercial Services & Re-selling:** Use the Sentrello name to market, promote, or sell third-party hosting services, managed services, support contracts, or software add-ons in a way that suggests official endorsement or authorization.
* **Confusing Similarity:** Use any mark, logo, or name that is confusingly similar to "Sentrello" or creates likelihood of consumer confusion regarding the official source of software or services.

---

## 4. Permissible Uses (No Prior Approval Required)

You may use the word "Sentrello" without written permission in the following limited contexts:
* **Educational & Commentary:** Referring to the official Sentrello platform in blog posts, news articles, tech reviews, podcasts, or documentation, provided the reference is truthful and non-misleading.
* **Community Compatibility:** Stating that a third-party extension or tool is compatible with our software (e.g., *"Custom plugin for Sentrello"* or *"Designed for use with Sentrello Core"*), provided it is clear that the project is independent and not built or endorsed by Sentrello LLC.

---

## 5. Questions and Trademark Violations
To request written brand authorization, report potential trademark misuse, or ask questions regarding this policy, please contact us at **support@sentrello.com**.
